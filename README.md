# MMO-Tool

Kho chứa các project, mỗi project nằm trong một thư mục riêng:

```text
MMO-Tool/
├── Chua-Online/
└── Money4Band/
```

- [Chùa Online](./Chua-Online/README.md): mã nguồn, tài nguyên và hướng dẫn chạy Chùa Online. Mở thư mục `Chua-Online/` trước khi chạy các lệnh của project.
- [Money4Band](./Money4Band/README.md): toàn bộ mã nguồn, cấu hình, tài nguyên, kiểm thử và giấy phép của Money4Band. Mở thư mục `Money4Band/` trước khi cài dependency hoặc chạy `python main.py`.

Thư mục `.github/` ở gốc chứa cấu hình GitHub; workflow Money4Band chạy trong `Money4Band/`.
